# m3ify

Material 3 (Expressive) для Spotify Desktop в стиле Pixel / Android 16. Ставится поверх Spotify, как spicetify, но без маркета, без расширений и без лишнего.

[English version](README.en.md)

## Установка
1. Двойной клик по `install.cmd`.
2. Запускай Spotify как обычно: его ярлыки и автозапуск теперь идут через m3ify. После обновления Spotify тема вернётся сама.

Чтобы иконка M3 была на панели задач: запусти Spotify, нажми ПКМ по его кнопке на панели задач → **Закрепить на панели задач**, затем запусти `reapply.cmd`.

Вернуть тему вручную: `reapply.cmd`. Удалить всё и вернуть оригинальный Spotify: `uninstall.cmd`.

## Что делает
- Перекрашивает дизайн-систему Spotify (Encore) в тональную палитру M3, цвет берётся из обложки текущего трека (Material You).
- Стиль Pixel / Android 16:
  - волнистый прогресс, как в медиаплеере Android;
  - толстый слайдер громкости;
  - плитки на главной в стиле быстрых настроек;
  - залитые карточки;
  - настройки Spotify в виде сгруппированных карточек Android с M3-переключателями.
- **Мои треки**: «Добавить папку с музыкой» включает в Spotify показ добавленных файлов и открывает выбор папки, «Открыть мои треки» переходит к ним.
- **Настройки**: **Ctrl+Alt+M** или кнопка рядом с громкостью. Можно выбрать цвет из обложки или фиксированный цвет, включить или выключить AMOLED-чёрный, волну, анимации и Canvas-видео.
- **Иконка M3**: стоит на ярлыке Spotify в «Пуске», на лаунчере `m3launch.exe` (около 30 КБ, собирается из `m3launch.cs` при установке) и на закрепе Spotify на панели задач. Незакреплённое окно и Alt+Tab показывают обычную иконку Spotify: её берёт из Spotify.exe сам Chromium, а изменённый Spotify.exe не запускается.
- **Язык**: русский и английский. В меню мода есть переключатель «Авто / Русский / English»; «Авто» берёт язык Spotify. Установщик пишет на языке Windows.

## Нагрузка
- Сам мод занимает около 40 КБ: CSS и несколько сотен строк JS без фреймворков и таймеров.
- Цвет пересчитывается только при смене трека, по картинке 24×24.
- Волна анимируется примерно с частотой 10 кадров в секунду в маленьком изолированном слое.
- Сам Spotify по-прежнему занимает около 700–800 МБ памяти, тема на это почти не влияет. Сильнее всего помогает скрыть Canvas и музыкальные клипы.

## Файлы
- `m3ify.ps1`: установщик и CLI (`install | apply | restore | uninstall | launch | status`).
- `m3launch.cs`: исходник лаунчера.
- `theme/m3.css`, `theme/m3.js`: сама тема.
- Установленная копия: `%LOCALAPPDATA%\m3ify`. Бэкап оригинального `xpui.spa` лежит в `backup\`.

Поддерживается только Spotify с spotify.com, версия из Microsoft Store не подходит.
