# m3ify

Material 3 для Spotify Desktop с дизайном по мотивам [Swiftify](https://shredos.dev/): крупная обложка, спокойные поверхности и цвет из музыки. Spicetify устанавливается автоматически, m3ify работает как его обычная тема и совместим с расширениями.

[English version](README.en.md)

## Установка
1. Скачай весь репозиторий (включая папку `theme`), распакуй и открой `install.cmd` обычным пользователем. При первой установке нужен интернет для загрузки Spicetify из официального релиза.
2. Запускай Spotify как обычно: его ярлыки и автозапуск теперь идут через m3ify. После обновления Spotify тема вернётся сама.

Чтобы иконка M3 была на панели задач: запусти Spotify, нажми ПКМ по его кнопке на панели задач → **Закрепить на панели задач**, затем запусти `reapply.cmd`.

Вернуть тему вручную: `reapply.cmd`. Удалить всё и вернуть оригинальный Spotify: `uninstall.cmd`.

## Что делает
- Перекрашивает дизайн-систему Spotify (Encore) в тональную палитру M3, цвет берётся из обложки текущего трека (Material You).
- Дизайн по мотивам Swiftify: карточка текущего трека на главной с рабочими кнопками, обложки и панели с округлыми углами, тональный плеер, волнистый прогресс и толстый слайдер громкости. Это тема официального Spotify, набор возможностей Swiftify не переносится.
- **Мои треки** открывает локальную коллекцию. «Добавить папку с музыкой» открывает настройки Spotify и подсказывает, где включить локальные файлы и выбрать источник.
- **Настройки**: **Ctrl+Alt+M** или кнопка рядом с громкостью. Можно выбрать цвет из обложки или фиксированный цвет, включить или выключить AMOLED-чёрный, волну, анимации и Canvas-видео.
- **Иконка M3**: стоит на ярлыке Spotify в «Пуске», на лаунчере `m3launch.exe` (около 30 КБ, собирается из `m3launch.cs` при установке) и на закрепе Spotify на панели задач. Незакреплённое окно и Alt+Tab показывают обычную иконку Spotify: её берёт из Spotify.exe сам Chromium, а изменённый Spotify.exe не запускается.
- **Язык**: русский и английский. В меню мода есть переключатель «Авто / Русский / English»; «Авто» берёт язык Spotify. Установщик пишет на языке Windows.

## Автофикс после обновления
- Лаунчер проверяет версию Spotify и наличие файлов темы перед запуском. Он ждёт завершения восстановления перед открытием Spotify и передаёт аргументы запуска.
- Задача Windows `m3ify AutoRepair <SID>` проверяет установку каждые две минуты, только когда Spotify и его установщик закрыты. Прямой запуск Spotify с закрепа будет исправлен после закрытия клиента либо при следующем запуске через лаунчер.
- При новом `xpui.spa` Spicetify создаёт свежий бэкап, затем применяет тему. Старый бэкап m3ify мигрируется только при совпадении версии Spotify.
- При ошибке восстановления выполняется одна попытка обновить Spicetify на версию Spotify. Несовместимый новый клиент может потребовать следующего выпуска Spicetify; ошибка остаётся в `%LOCALAPPDATA%\m3ify\repair.log`. Ручной повтор — `reapply.cmd`.
- `restore` возвращает оригинальный Spotify и приостанавливает автофикс до следующего `apply` или `install`. `uninstall.cmd` также удаляет задачу и возвращает ярлыки. Установленный Spicetify и сторонние расширения сохраняются; прежние настройки темы восстанавливаются.

## Нагрузка
Тема не содержит фреймворков. Цвет обложки кэшируется, DOM проверяется при изменениях интерфейса; постоянного JS-опроса нет. Автофикс — короткая задача Windows, отдельный постоянно работающий процесс не нужен. Canvas можно отключить в настройках темы.

## Файлы
- `m3ify.ps1`: установщик и CLI (`install | apply | repair | restore | uninstall | launch | status`).
- `m3launch.cs`: исходник лаунчера.
- `theme/m3.css`, `theme/m3.js`: сама тема.
- Установленная копия: `%LOCALAPPDATA%\m3ify`. Актуальными бэкапами управляет Spicetify. `backup\` используется только для миграции старой установки.

Поддерживается только Spotify с spotify.com, версия из Microsoft Store не подходит.

## Проверка разработки
`powershell -NoProfile -ExecutionPolicy Bypass -File tests/repair.ps1` проверяет восстановление на файловом стенде и собирает лаунчер, не меняя установленный Spotify.

Для UI: установи Node.js и Edge, выполни `npm install --no-save --package-lock=false playwright@1.62.1`, затем `node tests/ui.cjs`. Это браузерный стенд с имитацией API Spicetify; реальный запуск Spotify и обновление клиента он не заменяет.
